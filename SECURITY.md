# Security policy

## Supported versions

Only the latest release of Ration gets security fixes. Update with
`brew upgrade --cask ration` or from the
[latest release](https://github.com/IZZY-Agency/ration/releases/latest).

## Reporting a vulnerability

Please do not open a public issue for a security problem.

- Preferred: a private report through
  [GitHub Security Advisories](https://github.com/IZZY-Agency/ration/security/advisories/new).
- Or by email: <hello@izzy.agency>.

Say what you found, how to reproduce it and which version of Ration and macOS
you saw it on. You will get an answer, and credit in the release notes if you
want it.
